# โครงงาน: ระบบจัดการร้านกาแฟ (Cafe Ordering System)

ระบบหน้าร้าน (POS) สำหรับรับออเดอร์ การจัดการสต็อกวัตถุดิบเบื้องต้น และรายงานยอดขาย งานทุกชิ้นทำเป็นกลุ่ม ( 5 คน) ตั้งแต่สัปดาห์ที่ 1 และพัฒนาต่อเนื่องกันไปจนถึงวันนำเสนอในสัปดาห์ที่ 15 สิ่งที่วิเคราะห์หรือออกแบบไว้ในแต่ละสัปดาห์ จะถูกนำไปต่อยอดเป็นโค้ดที่ทำงานได้จริง ในสัปดาห์ถัดไปทันที
